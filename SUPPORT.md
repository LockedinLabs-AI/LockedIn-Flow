# Support

Use GitHub Discussions or Issues for reproducible community questions and bugs.
Include the macOS version, app version, expected behavior, actual behavior, and
content-free diagnostic metadata. Do not attach recordings, transcripts,
credentials, customer data, or protected health information.

Security reports must follow [SECURITY.md](SECURITY.md).

Community support is best-effort. Organizations that need deployment planning,
managed updates, compatibility commitments, or enterprise maintenance can
contact [LockedIn Labs](https://lockedinlabs.ai/contact/).
