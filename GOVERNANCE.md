# Governance

LockedIn Flow is maintained by LockedIn Labs. Maintainers set project direction,
review contributions, manage releases, and protect the security and privacy
boundary. Decisions prioritize user safety, local processing, compatibility,
and maintainability over feature count.

Contributions are evaluated for correctness, tests, security impact, scope,
licensing, and long-term ownership. Acceptance is not guaranteed. Material
changes to the data flow, trust boundaries, public interfaces, licensing, or
release process require maintainer approval and corresponding documentation.

The public issue tracker is the decision record for community-facing changes.
Security matters follow the private process in SECURITY.md.
